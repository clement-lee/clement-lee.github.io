# clement-lee.github.io

Source for [clement-lee.github.io](https://clement-lee.github.io), built with Jekyll and hosted on GitHub Pages.

- `_posts/`, `_pages/`, `_layouts/`, `_includes/`, `_sass/`, `_config.yml` — the Jekyll site itself.
- `slides/` — published talk slides (`*.html`/`*.pdf`) and their R Markdown sources (`slides/src/`). See [`slides/README.md`](slides/README.md) for the category layout and how to regenerate a deck from its source.
- `R/`, `data-visualisation/`, `extremes/` — rendered teaching notes (no source checked in here).
